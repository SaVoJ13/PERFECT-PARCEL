Склади звіт за: $ARGUMENTS (якщо порожньо — за сьогодні; якщо «тиждень» — за останні 7 днів).

## Збери факти (не з пам'яті, лише з джерел)
1. `git log main --since=<початок періоду> --oneline` і `gh pr list --state merged --search "merged:>=<дата>"` — що злито.
2. `gh pr list --state open` — що в роботі. `gh run list --branch main --limit 3` — стан CI.
3. `docs/governance/TASK_BOARD.md` — статуси; порахуй % завдань поточного етапу в статусі `Done`.
4. Журнали карток `docs/tasks/*.md` за період — що зроблено, що зламалось.
5. `docs/qa/BUG_REPORT.md` — відкриті P0/P1.
6. `docs/governance/OWNER_INBOX.md` — питання до Власника.
7. `docs/product/ROADMAP.md` — що лишилось до воріт етапу.

## Формат (українською, простими словами, до ~25 рядків)
```
📊 KEBAB STREET — ЗВІТ ЗА <період>
<🔴 ТЕРМІНОВО: … — лише якщо є>

Етап <N> «<назва>»: <x>% (<готово>/<всього> завдань)  ▓▓▓▓░░░░░░
Ворота етапу: <що вже є / чого бракує>

✅ Зроблено:
- <що змінилось для гри, людською мовою> (<ID>, доказ: <CI/скриншот>)

🔧 В роботі:
- <ID> — <що> — <хто>

⚠️ Проблеми / не перевірено:
- …

🐞 Помилки: P0 <n>, P1 <n>

📥 Чекає вас (з OWNER_INBOX, найважливіше першим):
1. <питання — варіанти — моя рекомендація>

👉 План на наступний день: …
```

## Після звіту
Збережи його в `docs/reports/<РРРР-ММ-ДД>.md` (для періоду — `docs/reports/<дата-початку>_<дата-кінця>.md`), закоміть у гілку `docs/report-<дата>`, відкрий PR і злий його самостійно (лише документ звіту, ADR-015).
Якщо Власнику потрібна дія — після звіту дай **одну** дію у форматі `/owner-step`.
