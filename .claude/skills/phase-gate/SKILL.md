Перевір ворота етапу $ARGUMENTS з `docs/product/ROADMAP.md`, розділ 3.

1. Для кожного пункту «Воріт» знайди доказ (CI, тести, `docs/qa/evidence/**`, анкети плейтесту). Нічого не приймай на слово.
2. Перевір, що в `docs/qa/BUG_REPORT.md` немає відкритих P0/P1 для цього етапу.
3. Перевір, що всі завдання етапу в `docs/governance/TASK_BOARD.md` мають статус `Done` або явно перенесені з рішенням Власника.
4. Поверни таблицю: пункт воріт → доказ (посилання) → ✅/❌, і підсумок: `Готово до огляду Власником` або `Не готово: <що бракує>`.

Ти не ставиш `Owner Approved`. Агент 0 передає підсумок Власнику з одним питанням: «Затверджуєте етап N?»
