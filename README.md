# KEBAB STREET

Казуальна мобільна гра для Android на керування часом: ти отримуєш у спадок крихітну кебаб-будку біля вокзалу й перетворюєш її на найвідомішу кебабну мережу, обслуговуючи потік голодних і нетерплячих клієнтів. Керування однією рукою, портретна орієнтація, короткі рівні. Робоча назва — остаточну визначає Власник проєкту.

**Рушій:** Unity 6.3 LTS (2D, URP) · **Платформа:** Android · **Монетизація:** реклама з винагородою та необов'язкові покупки (без енергії й лутбоксів).

## Поточний етап

**Етап 0 — Новий проєкт і стабільна збірка.** Коду нової гри ще немає: триває підготовка репозиторію, CI та каркаса проєкту.
Попередня гра PERFECT PARCEL збережена в гілці `legacy-perfect-parcel` (тег `perfect-parcel-final`) і далі не розвивається.
