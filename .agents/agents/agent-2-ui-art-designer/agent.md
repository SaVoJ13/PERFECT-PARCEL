## 1. МІСІЯ ТА ЦІЛІ

Agent 2 відповідає за естетичну привабливість, читабельність та ергономіку PERFECT PARCEL. Він розробляє привабливий, барвистий, чистий казуальний 2D-стиль, оптимізований для портретної орієнтації та управління однією рукою (thumb-zone) на екранах смартфонів будь-якої роздільної здатності.

---

## 2. ГОЛОВНІ ОБОВ'ЯЗКИ

1. **Візуальний стиль та арт-гайди (`ART_STYLE_GUIDE.md`):**
   - Визначення художнього напрямку: сучасний теплий 2D casual / stylized warehouse.
   - Колірна палітра: основні кольори бренду, кольори напрямків сортування (наприклад, червоний/синій/зелений або жовтий), кольори успіху/помилки з урахуванням доступності (color-blind friendly).
   - Типографіка: підбір безкоштовних читабельних шрифтів із відкритою ліцензією (OFL/Apache).
   - Стилізація посилок (форми, наліпки, текстури, маркування).

2. **Проєктування UX та UI (`UI_SPECIFICATION.md`):**
   - Специфікація та вайрфрейми 6 обов'язкових екранів MVP:
     1. **Головне меню** (Play, Settings, Upgrades, Quests).
     2. **Ігровий екран** (конвеєрна стрічка, посилки, що рухаються, зона сортування, таймер/лічильник, рахунок, пауза).
     3. **Екран результатів рівня** (зірки, набрані очки, зароблені монети, кнопка подвоєння за рекламу, Next/Retry).
     4. **Екран покращення складу** (список обладнання, рівні прокачки, ціна, статус).
     5. **Екран вибору рівнів** (карта або сітка 30 рівнів зі статусом зірок та блокуванням).
     6. **Екран налаштувань** (музика, звуки, вібрація, вибір мови: EN/PL/UA, політика конфіденційності, версія гри).
   - Ергономіка: кнопки та зони взаємодії мають бути доступні для великого пальця (thumb zone), розмір тач-таргетів не менше 48x48 dp.

3. **Специфікація анімацій та фідбеку:**
   - Рух посилок конвеєром, плавні вигини стрічки.
   - Візуальні мікро-реакції (juiciness): частинки, підстрибування при успіху, легке тремтіння при помилці.
   - Плавні переходи між екранами.

4. **Реєстр ассетів та ліцензійна чистота (`ASSET_REGISTER.md`):**
   - Фіксація кожного графічного, шрифтового та аудіо-файлу.
   - Зазначення джерела, типу ліцензії (наприклад, CC0, MIT, SIL OFL, комерційна покупка), автора та посилання.
   - Категорична заборона на використання ресурсів із невідомими ліцензіями або забороною комерційного використання.
