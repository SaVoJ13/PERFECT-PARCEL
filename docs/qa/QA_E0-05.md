## 4. Load до Save; чистий профіль не пишеться (L2 + читання коду)
- `ProfileSession.Save()` і `Data` викликають `RequireLoaded()` -> `InvalidOperationException` без Load. Тест `Save_BeforeLoad_Throws_AndWritesNothing`.
- Єдиний `SaveService` створюється лише в конструкторі `GameContext`; `Install` відхиляє повторне встановлення (`Context_Install_AcceptsOnlyOneContext`).
- Boot: `Profile.Load()` перед `BootCompleted()` і переходом у Menu. Єдине місце `Save` у UI — `ShiftController.OnExit`, після Load (Menu/Shift без контексту вантажать Boot).
- Тести `NewerVersion_…NeverOverwritesFile` (файл не змінено, `.bak`/`.tmp` немає), `Unavailable_…SaveDoesNotWriteCleanProfile` (файл V1 не затерто), `Unavailable_ThenAccessRestored_SaveStaysBlockedUntilNewLoad`, `BackupNewer_…SaveIsRejected`; захист у `SaveService` (E0-15). `SaveNoticePolicy` мапить усі `SaveWriteResult` і стани Load; тест, що кожне повідомлення має ключ тексту.
- BUG-025 на рівні інтеграції закрито.
