# ДОКУМЕНТАЦІЯ ТЕСТУВАННЯ ТА РЕЛІЗУ (QA & RELEASE DOCS)

У цьому каталозі зберігаються документи незалежного контролю якості:

1. **`TEST_PLAN.md`** — Комплексний план тестування 30 рівнів, 5 типів посилок, локалізації, збереження даних, офлайн-режиму та реклами. *(Відповідальний: Agent 5)*
2. **`TEST_RESULTS.md`** — Протоколи запусків, зафіксовані показники FPS, оперативної пам'яті та стабільності збірок. *(Відповідальний: Agent 5)*
3. **`BUG_REPORT.md`** — Реєстр відкритих та виправлених дефектів (P0–P3). *(Відповідальний: Agent 5)*
4. **`RELEASE_CHECKLIST.md`** — Фінальний контрольний список готовності додатку до публікації в Google Play Store. *(Відповідальний: Agent 5)*
