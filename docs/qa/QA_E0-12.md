## 4. Аналіз BUG-029 (причину НЕ ВСТАНОВЛЕНО)
Факти:
- Колір камери і фон контейнера `UiFactory.Screen` однакові, тому зі скриншота не видно, чи панель UI Toolkit малюється взагалі. Але кнопки мають власний помаранчевий фон і мали б бути видні навіть без шрифту — їх немає.
- У logcat немає жодного `Exception` від Unity/IL2CPP (у Release Unity пише необроблені винятки скриптів у тег `Unity`).
- У коді гри немає жодного `Debug.Log` (BUG-030), тож не видно, до якої сцени дійшла гра.
- У APK є: `UnityDefaultRuntimeTheme`, `PanelSettings`, шрифт `Inter-Regular` (`sharedassets0`), шейдери `Hidden/Internal-UIRDefault`, `Hidden/TextCore/*` (`globalgamemanagers`), ключі локалізації (три TextAsset). У журналі збірки CI: 3 сцени, `PanelSettings.asset` і тема імпортовані.

Гіпотези для розробника (перевіряти по черзі, не припущення-факти):
1. Панель UI Toolkit не рендериться в цьому конвеєрі (URP 2D Renderer + `PanelSettings`, створений `CreateInstance` у batchmode: тема, `renderMode`, порядок/`sortingOrder`, `targetDisplay`).
2. `Start()`/`Build()` не виконується або виконується в іншій сцені, ніж очікується (напр. Boot → `LoadScene(Menu)` до першого кадру).
3. `rootVisualElement` має нульовий розмір/масштаб на цьому екрані (1440x3120, `ScaleWithScreenSize` 1080x1920, `match 0.5`).
Рекомендація: Development Build або тимчасові `Debug.Log` у `ScreenController.Start/Build` і `BootController` (BUG-030); перевірка на телефоні до злиття; smoke-тест PlayMode/Player у CI, що меню має ≥1 видиму `Button`.
