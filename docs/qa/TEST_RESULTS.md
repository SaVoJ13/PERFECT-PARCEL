## 2. АУДИТ ПАМ'ЯТІ ТА ПРОДУКТИВНОСТІ (ZERO GC & 60 FPS)

- **Object Pooling:** Усі посилки генеруються заздалегідь у `ParcelPool.cs` (15 екземплярів). При деактивації або вильоті об'єкти очищуються і повертаються в чергу `_availableParcels` без викликів `Destroy()` чи `Instantiate()` у циклі сортування.
- **Event Bus:** Шина подій використовує статичні кешовані делегати без боксингу значущих типів (`struct` для всіх подій), що виключає періодичні мікрофризи GC Spikes.
- **Математика свайпу:** Векторний розрахунок кута через `Mathf.Atan2` оптимізовано та ізольовано лише на фазу завершення тачу (`TouchPhase.Ended`), мінімізуючи навантаження на процесор у кожному кадрі.
