## 7. Відхилення min API (BUG-009)
Офіційна документація Unity 6.3 (дата доступу 2026-11-10):
- https://docs.unity.com/en-us/engine/6000.3/manual/platform-specific/android/introducing/requirements-and-compatibility (перенаправлення з docs.unity3d.com/6000.3/Documentation/Manual/android-requirements-and-compatibility.html): «Unity supports Android 7.1 (API level 25) and above.»
- https://docs.unity.com/en-us/engine/6000.3/script-reference/unityeditor/androidsdkversions: найменший член — `AndroidApiLevel25`; `AndroidApiLevel24` немає; «The lowest API level listed here strictly corresponds to the lowest supported API level.»

Твердження виконавця підтверджено: API 24 у Unity 6.3 недосяжний. Критерій картки й ADR-017 (D-02 = API 24) буквально НЕ виконано; рішення — за Власником (`OWNER_INBOX` №8). Вердикт через це не блокується за дорученням Агента 0.

## 9. Знайдені проблеми
- **BUG-009 (P2)** — min API 25 замість 24 (розд. 7). Чекає рішення Власника.
- **BUG-010 (P3)** — `build-android.yml`, крок «Verify Project Files Are Committed»: pathspec `Assets/_Project Packages ProjectSettings` не охоплює корінь `Assets/` (зокрема `Assets/_Project.meta` і файли URP, що лишаться в корені, якщо `RelocateUrpGeneratedAssets` не спрацює). Файли game-ci `Assets/Editor/**` не внесено в `.gitignore` — ризик випадкового коміту (у `LESSONS.md` є лише попередження). Очікувано: перевіряти весь `Assets` з винятком службових шляхів game-ci або додати їх у `.gitignore`.
- **BUG-011 (P2, ризик, НЕ ПЕРЕВІРЕНО)** — `actions/cache` зберігає всю папку `Library` (≈1,8 ГБ), куди Unity кладе згенерований Gradle-проєкт (`Library/Bee/Android/Prj/IL2CPP/Gradle/…`). Припущення: при власному keystore Unity записує в Gradle-файли конфігурацію підпису (псевдонім, можливо паролі). Кеш `main` від 2026-11-08 (старий проєкт, збірка з підписом) існує (`gh cache list`), а кеші основної гілки (`main`) за правилами GitHub доступні для відновлення воркфлоу PR, зокрема з форків публічного репозиторію (політика схвалення — `first_time_contributors`). Не підтверджено: вміст кешу недоступний для читання поза воркфлоу. Не внесено цим PR (крок кешу був і раніше), але після злиття з'являться нові кеші `main`. Очікувано: Агент 4 у CI перевіряє лише імена файлів (`grep -rl` без виводу значень) і, якщо підтвердиться, виключає Gradle-проєкт із кешу / очищає кеш. Бажано до E0-04 (PR-тригер).
- **BUG-012 (P3)** — `docs/architecture/ARCHITECTURE.md` розд. 2: для `KebabStreet.Editor` вказано лише «Game», фактично ще 3 збірки URP. Обґрунтовано; потрібно лише дописати в документ (Агент 0).

Спостереження без номерів (не дефекти цього PR): дозвіл `android.permission.INTERNET` у маніфесті — типовий Unity, врахувати в анкеті Data safety (Етап 3); `PerformanceTestRun*.json` пакета тестів продуктивності потрапляють в APK (зазначено виконавцем); `m_PostProcessData` порожній; артефакт `UnityActivationFile` (файл запиту `.alf` машини CI, не секрет) публічний ще до закінчення терміну.
