# Анкета плейтесту (5 питань)

Дати тестувальнику телефон з грою на 10 хвилин без пояснень. Потім спитати:

1. Чи зрозуміли ви, що треба робити, без підказок? (так / частково / ні — що було незрозуміло?)
2. Що було найприємнішим? (одне речення)
3. Що дратувало або було незручно? (одне речення)
4. Чи хотілося б вам зіграти ще раз завтра? (оцінка 1–5)
5. На якому рівні ви зупинились і чому?

Агент 0 записує відповіді в `docs/qa/evidence/<етап>/playtest-<дата>.md` (без імен — «Тестувальник 1, 2...»).
Спостереження Власника під час гри (де гравець завис, де посміхнувся) важливіші за відповіді — їх теж записати.
