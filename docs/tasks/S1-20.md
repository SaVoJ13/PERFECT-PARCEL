## Безпечний порядок установки (adb)
1. `adb devices` — телефон видно.
2. `adb install -r KebabStreet.apk` — оновлення зі збереженням даних; якщо `Success` — все.
3. Якщо `INSTALL_FAILED_UPDATE_INCOMPATIBLE` (стара збірка з іншим підписом): СТОП, спитати Власника «так» на видалення старої тестової гри (зникне лише її збереження); тільки після «так» — `adb uninstall --user 0 com.savoj.kebabstreet` і повторна установка. Dual App (user 95) без окремого «так» не чіпати.
4. Запуск: `adb shell monkey -p com.savoj.kebabstreet -c android.intent.category.LAUNCHER 1`, перевірка `adb logcat -d | findstr "[KS]"`.
