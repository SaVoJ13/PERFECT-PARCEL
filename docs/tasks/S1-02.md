## Мета
Робоча дошка в чистому Core: збирання страви з інгредієнтів за рецептом, перевірка правильності, видача готової страви (передача клієнтові — інтерфейс для S1-03).

## Вхідні дані
`docs/design/GAME_DESIGN.md` розд. 3 (станції `bread`, `sauce`, `salad`, `board`, `bin`), розд. 5 (рецепти, правила збирання на дошці), розд. 2 (керування), розд. 12 (Q1); `docs/design/LEVEL_DESIGN.md` (які інгредієнти доступні на яких рівнях); код S1-01 (`Grill`, чергу дій `ShiftSimulation`).

## Що зробити
- Моделі `Board` (дошка), `Ingredient`, `Recipe` (кроки, optional, ціна, надбавки), результат перевірки страви (правильна / хибний порядок / зайвий інгредієнт).
- Команди: взяти піту, покласти м'ясо з гриля на дошку (використати `TakeMeat` із S1-01), додати салат/соус, зняти хибний інгредієнт, очистити дошку у смітник (штраф — параметр), видати страву. Усе через існуючу чергу дій.
- Доступність станцій за рівнем — параметр (`unlockLevel` / набір доступних станцій у конфізі зміни), а не гілки коду.
- Інтерфейс/подія видачі страви для клієнтів (S1-03), без самих клієнтів.
- Числа (час дій, штрафи, надбавки) — лише з конфіга; правила — лише з GAME_DESIGN.md. Неясне → варіанти в `docs/governance/OWNER_INBOX.md` не пиши (зона Агента 0): запиши в журнал картки готовий рядок і найменш ризикове припущення.
