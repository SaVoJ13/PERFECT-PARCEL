## Мета
Власник отримує готову до запуску збірку верхнього PR і короткий чек-лист «що перевірити, по одному пункту на дію». Агент, якщо телефон підключено, робить димову перевірку (запуск без вильотів на кожному екрані), але перевірка Власника лишається обов'язковою.

## Що зробити
1. Знайти зелений запуск CI на верхньому коді ланцюга (гілка `task/S1-13-placeholder-sfx`, запуск 43496413595) і дати точне посилання/спосіб узяти APK (артефакт `KebabStreet-Android-Builds`). Секретів нікуди не виводити.
2. **Якщо `adb devices` показує телефон** (раніше RZCX326349A): завантажити APK у нову порожню теку скретчпаду, встановити (`adb install -r`), запустити, пройти екрани (меню → рівень 1 → зміна → результат; згортання/повернення; повторний запуск) зі скриншотами й `adb logcat` без `Exception`/`FATAL`; докази в `docs/qa/evidence/S1-14/`. Нічого не видаляти й не очищати даних застосунку на телефоні. Телефона немає — записати «НЕ ПЕРЕВІРЕНО: телефон не підключено».
3. Написати `docs/qa/E1_PHONE_CHECKLIST.md` українською, простими словами: спершу одна дія «як поставити збірку на телефон» (кроки для Власника, без командного рядка, якщо можливо — через завантаження APK з GitHub Actions на телефон або кабель), далі нумерований перелік перевірок, **по одному пункту на дію**, у порядку гри: меню і рівні (замки/зірки), гриль (клади/зніми/викинь), прилавок (сердечка, значки замовлення), збирання і видача (одним тапом по клієнту — питання №30), пауза при згортанні, результат (Ще раз/Далі), навчання дядька Алі на L01, звуки, текст (кирилиця, польські літери, ★ у шрифті), вигляд на екрані (розмір кнопок, нічого не обрізано, портрет). Для кожного пункту: що зробити, що має бути, що відповісти («ОК» або що не так).
4. Оновити `BUG_REPORT.md` (результат димової перевірки) і `TEST_RESULTS.md`.
