## Мета
Гра озвучена мінімальними звуками: шипіння гриля при кладенні м'яса, «дзінь» каси при оплаті, радісний/сумний звук клієнта, сигнал пригорілого, дотик кнопки. Звуки або згенеровані кодом/скриптом (власні), або з вільних ліцензій (CC0) з реєстром.

## Вхідні дані
`docs/design/ART_STYLE_GUIDE.md` (звук, доступність), `GAME_DESIGN.md`, `docs/art/ASSET_REGISTRY.md` (формат реєстру), `Game/Views/*` (де відбуваються події: GrillPanel, CounterPanel/CounterFeed, ShiftScreen, ShiftInput), `ArtLibrary.cs` (приклад завантаження з Resources), `docs/governance/LESSONS.md` (урок про .meta: ручні .meta для імпортованих ресурсів не проходять крок CI «Verify Project Files Are Committed» — брати справжні .meta з CI-артефакту; тест реєстру має сканувати всі теки ресурсів).

## Що зробити
- Скрипт `tools/audio/generate_placeholder_sfx.ps1` (PowerShell, без Python; запис WAV 16-біт PCM моно 22–44 кГц вручну байтами) генерує короткі WAV (≤1 с) у `Assets/_Project/Resources/Audio/`: `sfx_sizzle`, `sfx_cash`, `sfx_happy`, `sfx_sad`, `sfx_burnt`, `sfx_tap`.
- Мінімальний програвач `Game/Views/SfxPlayer` (або `Game/Flow` без Unity + тонка обгортка): події → звук; відсутній файл — тиша без виняткових ситуацій; пауза гри не грає звуків; налаштування гучності/вимкнення — константа за замовчуванням ввімкнено (повзунок — не в цій картці).
- Підключити до подій: покласти м'ясо (sizzle), оплата клієнта (cash), клієнт пішов (sad), чайові/задоволений (happy), пригоріле (burnt), тап кнопки (tap). Логіку гри, Core, збереження не чіпати; події брати з наявних шарів (ShiftInput/CounterFeed/GrillView), нічого не вигадуючи в Core.
- Реєстр: рядки для кожного звуку в `docs/art/ASSET_REGISTRY.md` (або `docs/art/SOUND_REGISTRY.md`, обери одне і запиши), ліцензія Original; тест реєстру звуків, що сканує ВСІ теки аудіо.
- `.meta` для WAV: спершу напиши за прикладом наявних, запусти CI; якщо крок «Verify Project Files Are Committed» впаде через .meta — візьми справжні .meta з артефакту CI (тимчасовий крок upload-artifact, потім прибери його) як у S1-12.

## Критерії приймання (перевірювані)
- [ ] 6 WAV згенеровано скриптом, коректний заголовок, тривалість ≤1 с (тест перевіряє заголовок/довжину).
- [ ] Тест: кожен звук у реєстрі з ліцензією; тест сканує всі теки аудіо.
- [ ] Тест: програвач з відсутнім файлом не кидає винятків; на паузі звуки не запитуються.
- [ ] Тест: події (м'ясо покладено / оплата / клієнт пішов / пригоріле / тап) запитують відповідний звук (через інтерфейс-заглушку, без Unity-аудіо).
- [ ] Існуючі тести не послаблено, ≥1357, CI зелений, зміна розміру APK записана.
