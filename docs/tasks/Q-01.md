## Мета
Виміряна планка «комерційної» якості візуалу, UX, анімацій, звуку для кожного екрана.

## Що зробити
- WebSearch: 5–6 успішних мобільних ігор ресторанного тайм-менеджменту; що робить їх схожими на комерційний продукт.
- Підсумок: вимірювані критерії по екранах (меню, вибір рівнів, зміна, результат, пауза, навчання): анімації, частинки, переходи, звукові шари, вібрація, відгук ≤100 мс, типографіка, глибина (тіні, градієнти, об'єм). Джерела. Нічого не копіювати.
