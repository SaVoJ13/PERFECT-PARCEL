## 1. СИСТЕМА КОНТРОЛЬНИХ ТОЧОК ТА СТАТУСІВ

Жодна фаза не може вважатися завершеною, а робота над наступною фазою не може розпочатися, доки не пройдено повний життєвий цикл статусів:

```
[In Progress] ──► [Ready for Review] ──► [QA Verified] ──► [Owner Approved]
```

1. **`In Progress` (У роботі):** Агенти виконують завдання згідно з декомпозицією.
2. **`Ready for Review` (Готово до перевірки):** Агенти звітують Agent 0 про завершення коду / документації.
3. **`QA Verified` (Перевірено QA):** Agent 5 провів незалежну верифікацію та зафіксував відсутність критичних дефектів.
4. **`Owner Approved` (Затверджено Власником):** Власник проєкту особисто підтвердив результати фази. Лише цей статус дає дозвіл відкрити наступну фазу!

## 2. МАТРИЦЯ ФАЗ РОЗРОБКИ

| Фаза | Назва фази | Основна мета | Критерій переходу (Gate Criteria) |
| :--- | :--- | :--- | :--- |
| **PHASE 0** | Планування та архітектура | Повний пакет проєктної документації, порівняння технологічних стеків. | 12+ погоджених документів у `docs/`, вибір стеку, затвердження Власником. |
| **PHASE 1** | Технічний прототип | Перевірка базової механіки сортування на Android, налаштування CI/CD. | Працюючий APK з конвеєром, GitHub Actions створює артефакт, відсутність крашів. |
| **PHASE 2** | Розробка повного MVP | Реалізація всього ігрового контенту (30 рівнів, 5 посилок, прогресія, локалізація). | Усі 30 рівнів прохідні, локальні сейви стабільні, 3 мови працюють, 6 екранів готові. |
| **PHASE 3** | Дизайн, монетизація, аналітика | Полірування арт-стилю, UMP/GDPR згода, реклама Rewarded/Interstitial. | Реклама працює коректно, не ламає офлайн-режим, UMP відповідає правилам Google. |
| **PHASE 4** | QA та оптимізація | Стрес-тестування, усунення багів, профільування FPS та пам'яті. | 0 відкритих P0/P1 багів, 60 FPS на цільових смартфонах, звіт Agent 5 схвалено. |
| **PHASE 5** | Публікація в Google Play | Підготовка релізних матеріалів, метаданих, ассетів магазину, релізний білд. | Власник особисто натискає «Опублікувати» або дає письмову команду. |
| **PHASE 6** | Післярелізний розвиток | Моніторинг метрик залучення, збір краш-логів, планування v1.1. | Перші оновлення з виправленнями на основі відгуків реальних гравців. |

## 3. СУВОРІ ЗАБОРОНИ ТА ОБМЕЖЕННЯ

- 🚫 **Категорично заборонено** починати писати код гри під час Phase 0 (Phase 0 присвячена виключно плануванню та архітектурі).
- 🚫 **Категорично заборонено** переходити з Phase 1 у Phase 2 без робочого демо-APK на пристрої.
- 🚫 **Категорично заборонено** переходити в Phase 5 (Реліз) за наявності хоча б однієї відкритої проблеми рівня P0 або P1.
- 🚫 **Категорично заборонено** перескакувати фази.
