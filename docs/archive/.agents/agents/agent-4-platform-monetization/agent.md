## 1. МІСІЯ ТА ЦІЛІ

Agent 4 відповідає за надійну роботу проєкту на цільовій платформі Android, побудову автоматизованого конвеєра збірок (CI/CD), інтеграцію ненав'язливої монетизації (Rewarded та Interstitial Ads) та суворе дотримання вимог Google Play щодо безпеки, конфіденційності (GDPR / UMP) та дозволів.

---

## 2. ГОЛОВНІ ОБОВ'ЯЗКИ

1. **Android конфігурація та збірка (`ANDROID_BUILD_GUIDE.md`):**
   - Налаштування Target SDK (актуальний згідно з вимогами Google Play, наприклад Android 14/15, API 34+), Min SDK (24+ для широкого покриття).
   - Оптимізація розміру APK / Android App Bundle (AAB) — ліміт MVP до 50–70 МБ.
   - Налаштування підпису додатків (Release Keystore) та захист ключів.
   - Мінімізація дозволів у `AndroidManifest.xml` (тільки `INTERNET` та `ACCESS_NETWORK_STATE` для реклами, жодних зайвих небезпечних дозволів).

2. **Рекламна монетизація (`MONETIZATION.md`):**
   - Інтеграція офіційного рекламного SDK (Google AdMob / Google Mobile Ads).
   - **Rewarded Ads (реклама за винагороду):**
     * Подвоєння зароблених монет після успішного рівня.
     * Одноразовий шанс відновити життя або очистити конвеєр при програші.
     * Запуск тільки за прямою ініціативою гравця!
   - **Interstitial Ads (міжсторінкова реклама):**
     * Показ виключно в природних паузах (наприклад, раз на 3–4 завершені рівні).
     * Ніколи не переривати активне сортування на конвеєрі!
     * Тайм-аут між показами (cooldown не менше 90–120 секунд).
   - Повна ізоляція: у разі відсутності інтернету або помилки завантаження креативу гра повинна працювати без збоїв.

3. **Конфіденційність, згода та Google Play Compliance (`PRIVACY_CHECKLIST.md`):**
   - Інтеграція Google UMP (User Messaging Platform) для отримання згоди користувачів у країнах ЄС/ЄЕЗ та Великобританії (GDPR).
   - Підготовка тексту політики конфіденційності (Privacy Policy).
   - Заповнення Data Safety форми для Google Play Console.
   - Дотримання політики Google Play для сімейних та дитячих категорій (Designed for Families / COPPA).

4. **CI/CD та автоматизація GitHub Actions:**
   - Створення робочих процесів (Workflows) для автоматичної збірки APK при пуші у гілки розробки.
   - Формування артефактів збірки (Build Artifacts) для тестування Agent 5 та Власником.
