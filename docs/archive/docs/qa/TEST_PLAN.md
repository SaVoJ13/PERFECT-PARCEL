## 1. СТРАТЕГІЯ ТА ЦІЛІ ТЕСТУВАННЯ

План тестування спрямований на гарантування бездоганної стабільності, цілісності даних, плавності (60 FPS) та комплаєнсу гри на Android перед виходом у реліз.
**Головне правило QA (Golden Rule 5):** «Жодна функція не оголошується готовою без незалежного протоколу фактичної перевірки».

## 2. МАТРИЦЯ ТЕСТ-КЕЙСІВ MVP

### 2.1. Модуль 1: Геймплей та проходження 30 рівнів (`TC-GAME`)
| ID | Назва перевірки | Очікуваний результат | Пріоритет |
| :- | :--- | :--- | :---: |
| **TC-GAME-01** | Прохідність усіх 30 рівнів | Усі рівні від 1 до 30 можливо завершити на 3 зірки без блокування спавнера або неможливих таймінгів. | **P0** |
| **TC-GAME-02** | Поведінка 5 типів посилок | - Стандартна: коректний рух.<br>- Термінова: швидкість +40%, таймер 3 с.<br>- Крихка: при помилці забирає **2 серця** і розбивається з SFX.<br>- Важка: довгий свайп, -30% швидкості.<br>- Спеціальна: вимагає тапу-сканування перед вибором напрямку. | **P0** |
| **TC-GAME-03** | 3 напрямки сортування | Свайпи ліворуч (Синій), прямо (Зелений), праворуч (Червоний) валідуються без хибних детекцій. Кнопки доступності працюють аналогічно. | **P0** |
| **TC-GAME-04** | Буфер помилок та життя | Рівно 3 серця на рівні. При досягненні 0 сердець раунд негайно зупиняється з переходом на Fail Screen. | **P1** |
| **TC-GAME-05** | Лінія падіння (Drop Line) | Посилка, що перетнула лінію без дії гравця, падає і списує життя. | **P1** |
