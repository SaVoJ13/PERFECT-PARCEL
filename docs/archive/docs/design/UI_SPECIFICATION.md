## 1. ПРИНЦИПИ ЕРГОНОМІКИ ТА ПОРТРЕТНИЙ РЕЖИМ (PORTRAIT 9:16 / 9:20)

- **Орієнтація екрана:** Суворо вертикальна (Portrait Only). Блокування автоповороту для зручності швидкої гри в дорозі.
- **Зона досяжності великого пальця (Thumb-Zone Optimization):** Усі ключові інтерактивні кнопки (сортувальні стрілки, Next Level, Retry, Play) розташовані у нижній половині екрана.
- **Мінімальний розмір тач-елементів:** 48x48 dp (для запобігання хибним клікам).
- **Safe Area:** Повний облік Dynamic Island, каплеподібних вирізів (Notch) та системної панелі навігації Android.

## 2. МАКЕТИ 6 ОБОВ'ЯЗКОВИХ ЕКРАНІВ MVP

### 2.1. Екран 1: Головне меню (Main Menu)
- **Верхній блок:** Баланс монет (з іконкою `+`), кнопка налаштувань (іконка шестерні).
- **Центральний блок:** Логотип гри `PERFECT PARCEL`, анімована 2D-коробка, що махає рукою/підстрибує.
- **Нижній блок:**
  - Велика кнопка **«PLAY»** (зелена/жовта, пульсуюча).
  - Кнопка **«СКЛАД / UPGRADES»** (покращення обладнання).
  - Кнопка **«ЩОДЕННІ ЗАВДАННЯ»** (із червоною цяткою-сповіщенням при наявності нагород).

### 2.2. Екран 2: Ігровий екран (Gameplay HUD)
- **Верхній блок:**
  - Номер рівня (наприклад, `РІВЕНЬ 12`).
  - Лічильник життів: 3 червоних сердечка ❤️❤️❤️.
  - Лічильник посилок / Прогрес-бар (`18 / 35`).
  - Кнопка паузи `[ || ]`.
- **Центральний простір:**
  - Вертикальний конвеєр, по якому зверху вниз рухаються посилки.
  - Активна зона сортування (Decision Zone) з напівпрозорою лінією дедлайну (Drop Line).
- **Нижній блок:**
  - 3 великі сортувальні кнопки-стрілки з піктограмами:
    * ⬅️ Синя (Коло)
    * ⬆️ Зелена (Трикутник)
    * ➡️ Червона (Ромб)
  - Гравець може керувати як свайпом по посилці, так і тапом по цих кнопках.

### 2.3. Екран 3: Результати рівня (Win / Fail Screen)
- **При перемозі (Level Complete):**
  - Анімація 1–3 золотих зірок.
  - Нараховані монети (`+65 Coins`).
  - Велика виділена кнопка **`[Подвоїти нагороду x2 (Відео)]`** (Rewarded Ad).
  - Кнопка **`[Наступний рівень ➔]`**.
  - Кнопка повтору `[ ↺ ]`.
- **При поразці (Level Failed):**
  - Причина поразки («Конвеєр переповнено!» або «Крихкий вантаж розбито!»).
  - Кнопка швидкого відновлення **`[Другий шанс: +2 серця (Відео)]`** (з 5-секундним таймером).
  - Кнопка повтору `[Спробувати знову]`.
  - Кнопка виходу в меню.

### 2.4. Екран 4: Покращення складу (Warehouse Upgrades)
- Список 7 доступних технологій (Плавний конвеєр, Захисний буфер, Авто-сканер тощо).
- Кожна картка містить: іконку, поточний рівень (зірки 1–5), опис ефекту, кнопку купівлі з ціною в монетах.
- Якщо монет недостатньо — кнопка стає неактивною і показує сіру суму.

### 2.5. Екран 5: Вибір рівнів (Level Select Grid)
- Скрол-карта або сітка 30 рівнів (розбита на 6 тірів по 5 рівнів).
- Кожен рівень показує свій номер, кількість зароблених зірок (0–3) або замок 🔒.
- Замкнені тіри показують вимогу: «Потрібно ще 4 зірки для розблокування».

### 2.6. Екран 6: Налаштування (Settings Modal)
- Перемикач музики (Вкл / Викл, слайдер гучності).
- Перемикач звукових ефектів (SFX).
- Перемикач вібрації (Haptic Feedback) — критично для відчуття клацання при сортуванні.
- Вибір мови: прапорці **English**, **Polski**, **Українська**.
- Кнопка «Політика конфіденційності» (Privacy Policy) — обов'язкова вимога Google Play.
- Кнопка скидання згоди GDPR/UMP («Змінити налаштування конфіденційності»).
- Номер поточної версії білда (наприклад, `v1.0.0 (Build 1)`).
