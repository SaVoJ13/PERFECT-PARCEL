## 1. БАЗОВА КОНЦЕПЦІЯ ТА ЦІЛЬОВИЙ ДОСВІД (CORE VISION)

PERFECT PARCEL — це яскрава, динамічна казуальна 2D-гра-головоломка з елементами менеджменту складу для мобільних пристроїв Android. Гравець бере на себе роль оператора головного сортувального терміналу міського логістичного хабу.

**Ключові стовпи геймплею (Design Pillars):**
1. **Зрозуміло за 5 секунд (Instant Clarity):** Гравець одразу бачить посилку, маркування та 3 сортувальні напрямки.
2. **Тактильне задоволення (Juicy Feedback):** Кожне вдале сортування супроводжується приємним звуком, анімацією підстрибування коробки та ефектом частинок (конфетті/пилок).
3. **Сесії 60–90 секунд:** Ідеальний темп для гри у транспорті або короткої перерви з керуванням великим пальцем однієї руки (One-Thumb Portrait Mode).
4. **М'яка складна крива:** Від розслабленого сортування однакових коробок до швидких комбо з п'ятьма різними типами вантажів.

## 3. МЕХАНІКА КОНВЕЄРА ТА ЗОНИ СОРТУВАННЯ

1. **Рух конвеєра:**
   - Посилки спавняться у верхній частині конвеєра і рухаються вниз із фіксованою або динамічною швидкістю (від 200 до 600 пікселів/сек залежно від рівня).
   - Між посилками підтримується мінімальна безпечна дистанція (спавн-інтервал 0.8–2.0 сек).
2. **Зона прийняття рішень (Decision Gate):**
   - У нижній третині екрана розміщена активна зона сортування, де гравець повинен встигнути виконати дію до того, як посилка досягне кінця стрічки (Drop Line).
   - Якщо посилка перетинає Drop Line без дії гравця — вона падає повз і зараховується помилка (Missed Parcel).
3. **Управління (Controls):**
   - **Основне:** Швидкий свайп по посилці в напрямку однієї з трьох ліній.
   - **Альтернативне (Accessibility):** Три великі кнопки-стрілки внизу екрана для гри тапом без свайпів.

## 4. ТРИ СОРТУВАЛЬНІ НАПРЯМКИ MVP

Конвеєр розгалужується на 3 кольорові зони доставки:
- 🔵 **Напрямок 1 (Ліво / Синій) — «Локальна міська доставка (Local / Blue)»**:
  - Призначений для стандартних та повсякденних вантажів із синім маркуванням.
- 🟢 **Напрямок 2 (Прямо / Зелений) — «Екологічна / Наземна пошта (Ground / Green)»**:
  - Призначений для великогабаритних та екологічних вантажів із зеленим маркуванням.
- 🔴 **Напрямок 3 (Право / Червоний) — «Авіа / Експрес термінал (Air Express / Red)»**:
  - Призначений для термінових та особливо цінних відправлень із червоним або помаранчевим маркуванням.

*Примітка щодо доступності (Colorblind Accessibility):* Кожен напрямок, окрім кольору, має унікальну геометричну піктограму (наприклад: Синій = Коло, Зелений = Трикутник, Червоний = Квадрат/Ромб).

## 6. УМОВИ ПЕРЕМОГИ, ПОРАЗКИ ТА ОЦІНКА

1. **Життя / Помилки:**
   - На рівні гравцеві дається **3 життя (Hearts / Error Buffer)**.
   - 1 неправильне сортування або пропущена посилка = -1 життя (для крихкої посилки = -2).
   - Втрата всіх життів = поразка (Fail Screen з пропозицією другого шансу за перегляд Rewarded Ad).
2. **Умови проходження рівня:**
   - Відсортувати цільову кількість посилок (наприклад, 20 посилок на рівні 1, до 60 на рівні 30) або втримати конвеєр протягом фіксованого часу (60–90 секунд).
3. **Зіркова система (1–3 зірки):**
   - ⭐️ 1 зірка: Рівень пройдено (залишилося хоча б 1 життя).
   - ⭐️⭐️ 2 зірки: Рівень пройдено з точністю понад 85% та збереженням мінімум 2 життів.
   - ⭐️⭐️⭐️ 3 зірки: 100% ідеальне проходження (Perfect Parcel) без жодної помилки.
