## 1. ВІЗІЯ ТА ЖАНР
PERFECT PARCEL — це казуальна мобільна 2D-гра-головоломка (Casual Puzzle / Light Sorting Management) для Android з портретною орієнтацією та керуванням однією рукою.
Гравець керує сортуванням посилок на складському конвеєрі, направляючи їх у відповідні канали доставки на основі візуальних характеристик (колір, тип, маркування, терміновість).

## 2. ОБСЯГ ТА МЕЖІ MVP (MVP SCOPE)

| Компонент | Обсяг MVP | Опис |
| :--- | :--- | :--- |
| **Рівні** | 30 рівнів | Поступова крива складності від простих до челендж-рівнів |
| **Типи посилок** | 5 типів | Звичайна, Термінова, Крихка, Важка, Спеціальна |
| **Сортувальні напрямки** | 3 напрямки | Наприклад: Ліво, Прямо, Право |
| **Локація** | 1 локація | Базовий міський сортувальний склад |
| **Валюта** | Монети | Нараховуються за успішне проходження рівнів |
| **Покращення складу** | 5–10 покращень | Збільшення швидкості обробки, розширення ліміту помилок тощо |
| **Досягнення** | 10 ачівок | Внутрішньоігрові нагороди за майстерність |
| **Щоденні завдання** | 3 типи | Завдання на сортування певної кількості посилок |
| **Локалізація** | 3 мови | EN (Англійська), PL (Польська), UA (Українська) |
| **Збереження** | Локальне | JSON / PlayerPrefs із захистом цілісності даних |
| **Інтернет** | Не обов'язковий | 100% функціональний геймплей в офлайні |
| **Монетизація** | Реклама (F2P) | Rewarded Ads (подвоєння монет) + Interstitial Ads (у паузах) |
