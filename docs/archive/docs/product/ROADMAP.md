## ЕТАПИ РОЗРОБКИ ТА КРИТЕРІЇ ПЕРЕХОДУ (PHASES)

### 📌 PHASE 0 — ПЛАНУВАННЯ ТА АРХІТЕКТУРА (ПОТОЧНА ФАЗА)
- **Мета:** Сформувати повний, узгоджений пакет із 12+ документів планування до написання будь-якого коду гри.
- **Статус:** **Ready for Review (Пакет документації повністю сформовано, очікує Owner Approved)**.
- **Результати:**
  * Затверджено стек: Unity 2022.3 LTS (C#), Target SDK 34+ (ADR-005).
  * Спроєктовано геймплей: Core Loop, 30 рівнів у `LEVEL_DESIGN.md`, економіку в `ECONOMY_DESIGN.md`.
  * Спроєктовано інтерфейс: 6 обов'язкових екранів у `UI_SPECIFICATION.md`, стиль у `ART_STYLE_GUIDE.md`.
  * Спроєктовано архітектуру: `ARCHITECTURE.md` (атомарне збереження JSON, Event Bus, Object Pool).
  * Спроєктовано монетизацію: `MONETIZATION.md`, `PRIVACY_CHECKLIST.md` (AdMob, UMP, GDPR).
  * Спроєктовано контроль якості: `TEST_PLAN.md` (30 рівнів), `RELEASE_CHECKLIST.md` (50+ пунктів).

### ⏳ PHASE 1 — ТЕХНІЧНИЙ ПРОТОТИП (НАСТУПНА ФАЗА)
- **Мета:** Перевірити на практиці, що обраний стек (Unity 2022.3) дозволяє реалізувати базовий функціонал.
- **Очікувані результати:**
  1. Ініціалізація проєкту Unity 2022.3 LTS (URP 2D).
  2. Працюючий конвеєр з плавним рухом стрічки.
  3. Спавнер посилок з Object Pooling.
  4. Обробка тапу/свайпу у 3 сортувальні напрямки.
  5. Базова детекція правильного та неправильного сортування.
  6. Налаштований пайплайн Game-CI у GitHub Actions для автоматичної збірки APK.
- **Контрольна точка:** Власник отримує перший робочий тестовий APK-файл для власноручного тесту на Android.

---

### ⏳ PHASE 2 — РОЗРОБКА ПОВНОГО MVP
- **Мета:** Створити функціонально завершену гру без реклами (30 рівнів, 5 посилок, прогресія, локалізація EN/PL/UA, локальне збереження).
- **Контрольна точка:** Повна версія гри на пристрої без блокерів P0/P1.

---

### ⏳ PHASE 3 — ДИЗАЙН, МОНЕТИЗАЦІЯ ТА АНАЛІТИКА
- **Мета:** Інтеграція Google Mobile Ads SDK (Rewarded x2, другий шанс, Interstitial у паузах), форма згоди Google UMP (GDPR), фінальний арт і звуковий дизайн.
- **Контрольна точка:** Повністю готова до релізу версія з працюючою рекламою.

---

### ⏳ PHASE 4 — QA ТА ОПТИМІЗАЦІЯ
- **Мета:** Стрес-тестування, усунення всіх багів, досягнення стабільних 60 FPS та ліміту пам'яті до 180 МБ.
- **Контрольна точка:** Офіційний звіт Agent 5 про повну готовність до релізу (0 відкритих P0/P1 дефектів).

---

### ⏳ PHASE 5 — ПУБЛІКАЦІЯ В GOOGLE PLAY
- **Мета:** Підготовка метаданих, скріншотів, проходження модерації та публікація у Google Play Store.
- **Контрольна точка:** Особиста письмова команда Власника на публікацію.

---

### ⏳ PHASE 6 — ПІСЛЯРЕЛІЗНИЙ РОЗВИТОК
- **Мета:** Моніторинг краш-логів (ANR/Crashes), аналіз конверсії та утримання гравців, планування оновлень v1.1+.
