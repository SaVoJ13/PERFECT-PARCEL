# АРХІТЕКТУРНА ДОКУМЕНТАЦІЯ (ARCHITECTURE DOCS)

1. **`ARCHITECTURE.md`** — Загальна архітектурна модель клієнта гри (State Machine, Event Bus, Object Pooling, система збереження/завантаження, менеджер аудіо та локалізації). *(Відповідальний: Agent 0 / Agent 3)*
2. **`TECHNICAL_SPEC.md`** — Технічні вимоги, вибір рушія, версії мов програмування, вимоги до апаратного забезпечення (RAM, GPU, Android Target SDK). *(Відповідальний: Agent 0 / Agent 4)*
