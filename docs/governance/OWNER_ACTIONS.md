# Дії, які може виконати лише Власник

Агенти не мають доступу до ваших акаунтів. Агент 0 проситиме ці дії **по одній**, у форматі `/owner-step`, коли настане час. Список — щоб бачити все наперед.

| ID | Дія | Навіщо | Етап | Статус |
|---|---|---|---|---|
| O-01 | Перевірити, що на ПК встановлені Git, GitHub CLI (`gh`, з входом у ваш акаунт) і Claude Code | Агенти самі читають CI і створюють PR, без вашої участі в логах | 0 | ☐ |
| O-02 | Перевірити `adb` на ПК і «Налагодження USB» на Samsung | Агенти самі ставлять гру на телефон і роблять скриншоти | 0 | ☐ |
| O-03 | Після переходу на Unity 6.3 — за потреби оновити секрети ліцензії Unity у GitHub | Без ліцензії CI не збирає гру | 0 | ☐ |
| O-04 | Запустити гру на телефоні (поки меню і порожня зміна) і підтвердити, що працює | Ворота Етапу 0 | 0 | ☐ |
| O-05 | Плейтест: дати гру 3–5 знайомим (анкета `docs/qa/PLAYTEST_FORM.md`) | Чи цікаво грати — до монетизації | 1 | ☐ |
| O-06 | Почати збирати 12+ тестувальників (друзі, родина, спільноти) з акаунтами Google | Обов'язкове закрите тестування 14 днів для нового особистого акаунта | 2 | ☐ |
| O-07 | Перевірити акаунт розробника Google Play (верифікація особи, статус) | Без нього немає публікації і покупок | 2 | ☐ |
| O-08 | Створити ключ підпису (keystore) і зробити 2 резервні копії поза ПК; внести секрети в GitHub Secrets | Без ключа неможливо оновлювати гру | 3 | ☐ |
| O-09 | Створити акаунт AdMob, застосунок і рекламні блоки | Справжня реклама | 3 | ☐ |
| O-10 | Налаштувати платіжний профіль (продавця) в Play Console | Без нього покупки не працюють | 3 | ☐ |
| O-11 | Створити продукти покупок у Play Console за `iap_catalog.json` і додати себе як тестувальника ліцензій | Тестові покупки без списання грошей | 3 | ☐ |
| O-12 | Створити проєкт Firebase (якщо D-04 = так) | Аналітика і звіти про краші | 3 | ☐ |
| O-13 | Увімкнути публічну сторінку для політики конфіденційності (GitHub Pages) | Google Play вимагає URL політики | 3 | ☐ |
| O-14 | Заповнити в Play Console: вікову класифікацію, Data safety, цільову аудиторію — за чернетками агентів | Обов'язково перед тестуванням | 5 | ☐ |
| O-15 | Запросити тестувальників у закрите тестування і стежити, щоб вони були активні 14 днів | Доступ до продакшну | 5 | ☐ |
| O-16 | Затвердити сторінку магазину і ціни | Ваше рішення | 5 | ☐ |
| O-17 | Натиснути публікацію (поступове розгортання) | Лише ви публікуєте | 6 | ☐ |

Агент 4 перед кожною дією етапів 3–6 перевіряє актуальні правила Google (вони змінюються) і, зокрема, які ваші контактні дані стануть публічними в магазині при продажі покупок.
