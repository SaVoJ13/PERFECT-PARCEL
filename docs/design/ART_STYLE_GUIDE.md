## 1. ВІЗУАЛЬНИЙ НАПРЯМОК ТА АТМОСФЕРА

- **Жанровий стиль:** 2D Casual / Modern Stylized Vector з теплими, соковитими відтінками.
- **Атмосфера:** Дружній, організований та чистий автоматизований логістичний склад (ніякого бруду чи тьмяних кольорів промислової антиутопії).
- **Форми:** М'які заокруглені кути (border-radius на всіх коробках, кнопках та панелях), чіткі товсті контури (1.5–2 px) для високої контрастності на мобільних екранах.
- **Текстурування:** Спрощене плоске затінення (Cel-shading / Soft Gradient), мінімальний шум.

## 2. КОЛІРНА ПАЛІТРА ТА ДОСТУПНІСТЬ (ACCESSIBILITY)

### 2.1. Базові кольори інтерфейсу та оточення
- **Фон складу (Warehouse Floor):** `#2C3440` (Глибокий м'який індиго-сірий для фокусу на конвеєрі).
- **Стрічка конвеєра (Belt):** `#1E232A` з рухомими світлими шевронами `#3A4454`.
- **Каркас конвеєра:** Металевий матовий `#D1D5DB`.
- **Основний фон панелей UI:** Білий `#FFFFFF` та теплий кремовий `#F8FAFC`.
- **Акцентні кнопки:** Соковитий жовто-помаранчевий `#F59E0B` (Play / Upgrade).

### 2.2. Кольори сортувальних ліній та піктограми (Colorblind Friendly)
Для гарантії розрізнення ліній гравцями з будь-якою формою дальтонізму (протанопія, дейтеранопія, тританопія), кожна лінія має унікальний колір + геометричну піктограму + напис:
- 🔵 **Лінія 1 (Міська / Local):**
  - Колір: Синій `#2563EB` (Sky Blue)
  - Форма/Піктограма: **Коло** ⚪
- 🟢 **Лінія 2 (Наземна / Ground):**
  - Колір: Смарагдовий зелений `#10B981` (Emerald Green)
  - Форма/Піктограма: **Трикутник** 🔺
- 🔴 **Лінія 3 (Авіа-експрес / Express):**
  - Колір: Насичений малиново-червоний `#EF4444` (Vibrant Coral Red)
  - Форма/Піктограма: **Ромб / Діамант** 🔶

## 3. ВІЗУАЛЬНИЙ ДИЗАЙН 5 ТИПІВ ПОСИЛОК

1. **Стандартна (Standard Parcel):**
   - Крафтовий теплий картон `#D97706` із пакувальною стрічкою відповідного кольору лінії (синій/зелений/червоний) та білою адресною наліпкою.
2. **Термінова (Express Parcel):**
   - Яскравий помаранчевий корпус `#FB923C` з діагональними жовто-чорними шевронами попередження та миготливим круглим LED-індикатором таймера.
3. **Крихка (Fragile Parcel):**
   - Білосніжна посилка `#F1F5F9` з великим червоним знаком келиха та піктограмами «UP» (стрілки вгору).
4. **Важка (Heavy Freight):**
   - Масивний темний дубовий ящик `#78350F` із залізними кутовими накладками `#4B5563` та металевими заклепками.
5. **Спеціальна (Secured Container):**
   - Сріблясто-титановий кейс `#94A3B8` із червоним цифровим замком, який після тапу перемикається на зелений і показує напрямок сортування.
