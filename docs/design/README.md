# ДОКУМЕНТАЦІЯ ДИЗАЙНУ ТА АРТУ (DESIGN & ART DOCS)

У цьому каталозі зберігаються специфікації геймдизайну, користувацького інтерфейсу та художнього стилю PERFECT PARCEL:

1. **`GAME_DESIGN.md`** — Правила гри, поведінка конвеєра, жести, механіки сортування, умови перемоги/поразки. *(Відповідальний: Agent 1)*
2. **`LEVEL_DESIGN.md`** — Таблиця та параметри 30 рівнів MVP (частота спавну, швидкість, цільові показники зірок). *(Відповідальний: Agent 1)*
3. **`ECONOMY_DESIGN.md`** — Баланс монет, вартість і ефекти 5–10 покращень складу, 10 досягнень, щоденні завдання. *(Відповідальний: Agent 1)*
4. **`UI_SPECIFICATION.md`** — Макети та логіка 6 обов'язкових екранів (Main Menu, Gameplay, Result, Upgrades, Level Select, Settings). *(Відповідальний: Agent 2)*
5. **`ART_STYLE_GUIDE.md`** — Колірна палітра, візуальний стиль 2D casual, типографіка, дизайн 5 типів посилок. *(Відповідальний: Agent 2)*
6. **`ASSET_REGISTER.md`** — Реєстр усіх графічних, звукових та шрифтових ресурсів з ліцензіями. *(Відповідальний: Agent 2)*
