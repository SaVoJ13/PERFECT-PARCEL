# KEBAB STREET — Дизайн рівнів (Етап 1: рівні 1–5)

**Автор:** Агент 1. **Статус:** чернетка E0-10, L0. Основа — `GAME_CONCEPT.md` розд. 8 (локація 1). Правила — `GAME_DESIGN.md`.
**Правило чисел:** усі числа — «припущення, перевірити симуляцією». У таблицях — лише цілі за концепцією; пороги зірок і хвилі — формула/позначка `[S]` = «визначає економічна симуляція та бот-тест». Остаточні значення — `Assets/_Project/Resources/Config/levels/L01.json`…`L05.json`.
**Ритм:** нове -> практика -> нове -> нове + складніше -> практика. Нове не частіше ніж кожен другий рівень, окрім навчальних (1–3).

## 2. Загальні параметри рівня (ключі `levels/Lxx.json`)
```json
{
  "id": "L01",
  "location": 1,
  "durationSec": 0,
  "counterSlots": 0,
  "goal": { "type": "serve", "count": 0 },
  "stars": { "two": { "type": "coins", "value": 0 },
             "three": { "condition": "noLostCustomers" } },
  "lose": { "maxLostCustomers": null },
  "grill": { "slots": 0, "cookSec": 0, "burnAfterDoneSec": 0, "burntPenaltyCoins": 0 },

  "storyKeys": { "intro": "story.l01.intro", "outro": "story.l01.outro" }

```
Нулі й порожні — значення з симуляції `[S]`. Типи цілей: `serve`, `coins`. Умови зірок: `noLostCustomers`, `noBurnt`, `combo`.

## 3. Рівень 1 — «Перший кебаб» (навчальний)
- **Ціль:** `goal.type=serve`, `goal.count` (концепція: 3 клієнти).
- **Клієнти:** тільки `olya`. Один клієнт за раз (послідовно), інтервал між приходами великий; терпіння `[S]` дуже високе.
- **Нове:** гриль (сире -> готове), піта, видача. Підказки по кроках від дядька Алі (`tutorial.l01.*`).
- **Захисти:** програти неможливо «несправедливо»: втрата клієнтів не рахується; пригоріле без штрафу; поразка лише якщо час повністю вийшов (час із великим запасом `[S]`).
- **Зірки:** ★ ціль; ★★ швидкість (`stars.two`, серед `serve` — час/кількість `[S]`); ★★★ жодного пригорілого шматка.
- **Рішення гравця:** коли поставити м'ясо, поки збираєш пітy (перше тривіальне «що першим»).

## 4. Рівень 2 — «Студенти по дорозі на пари» (практика)
- **Ціль:** `serve`, `goal.count` (концепція: 6).
- **Клієнти:** `olya` ×N. Нових механік немає; одночасно приходять 2 клієнти (двічі в зміні), щоб з'явилась потреба вибору, кого обслужити першим.
- **Гриль:** два шматки м'яса в роботі; пригоріле все ще без штрафу, але займає слот (початок відчуття тиску).
- **Зірки:** ★★ швидше `[S]`; ★★★ без пригорілого.
- **Мета дизайну:** закріпити цикл «м'ясо -> піта -> видача», показати, що два клієнти = вибір пріоритету.

## 5. Рівень 3 — «Таксист Марко поспішає» (нове: терпіння, черга, соус)
- **Ціль:** `serve`, `goal.count` (концепція: 8), `lose.maxLostCustomers` (концепція: 1).
- **Клієнти:** `olya` + `marko` (мало терпіння, завжди гострий соус). Марко приходить у середині зміни, коли в черзі вже стоїть Оля: гравець вирішує, обслужити Марко негайно (чайові) чи закінчити вже розпочатого.
- **Нове:** сердечка терпіння, черга за слотами, соус (гострий, вперше). Підказки: `tutorial.l03.*`.
- **Захисти (навчання, програти не «несправедливо»):** поразка пояснюється екраном (`lost.reason.customersLeft`); терпіння Марка в перші 20 с не спадає (`[S]`, лише рівень 3, поступова переміна).
- **Зірки:** ★ ціль; ★★ швидше `[S]`; ★★★ жодного втраченого клієнта.
- **Нюанс до концепції:** з цього рівня втрата клієнтів зараховується в умову поразки (`lose.maxLostCustomers`).

## 6. Рівень 4 — «Бабуся Ганна: тільки без цибулі!» (нове: салат, прохання)
- **Ціль:** `goal.type=coins`, `goal.coins` (концепція: стартова пропозиція 150).
- **Клієнти:** `olya`, `marko`, `hanna`. Ганна просить `request.exclude = onion`: гравець має вручну не додати цибулю з салатного бару (салат без цибулі = окремий тап, див. `ingredient.*`).
- **Нове:** салатний бар (салат, цибуля), особливе прохання. Підказки: `tutorial.l04.*`.
- **Рішення гравця:** салат додає ціну, але ризик хибної страви; не додавати — менше грошей, але безпечно.
- **Зірки:** ★ ціль монет; ★★ більша сума `[S]`; ★★★ жодної хибної страви.
- **Помилка і зрозуміла поразка:** хибна страва = клієнт показує значок цибулі й втрачає терпіння, на екрані `lost.reason.wrongDishes`.

## 7. Рівень 5 — «Обідній потік» (практика/поєднання)
- **Ціль:** `coins`, `goal.coins` (концепція: стартова пропозиція 200).
- **Клієнти:** усі три типи, щільніший потік двома хвилями (початок і середина).
- **Нових механік немає**; все з рівнів 1–4 разом. Підсилення: хвиля 3 клієнтів одночасно, щоб перевірити пріоритизацію і гриль.
- **Зірки:** ★ ціль; ★★ `[S]`; ★★★ комбо (`stars.three.condition=combo`, значення x`[S]`, концепція дозволяє комбо x5, але у Етапі 1 поріг м'якший — питання Q3).
- **Мета:** ворота Етапу 1 («хочу ще»): цей рівень має давати відчуття «я встигаю, але ледь» без стресу несправедливості.

## 9. Вимоги до перевірки (для Агентів 3/5)
- Кожен рівень проходимий без бустерів і без покращень (бот-тест).
- Рівень 1: бот із «ідеальним» і з «повільним» профілем має пройти ★; рівень не програється за помилками.
- Для кожного рівня звіт симуляції: запас часу, % клієнтів, що пішли, середня зірка для профілю «без витрат, 2★» (`tools/economy_sim.py`; скрипт ще не створено — залежить від E1).
- Пороги зірок у `levels/*.json` розставляються так, щоб профіль «без витрат» стабільно мав ★★ у 70–80% спроб `[S]`.
